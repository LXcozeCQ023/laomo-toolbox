# 老默工具箱 · 视频下载器

一个本地运行的视频 / 图文下载工具。粘贴链接，选好保存目录，点下载。所有解析和下载都在本机完成，不经过任何第三方服务器。

## 目录结构

| 目录 | 平台 | 状态 |
| --- | --- | --- |
| `video-downloader-macos/` | macOS | 主力版本，本机长期在用 |
| `video-downloader/` | Windows | 上游源码保留，未在本机运行 |

## 快速开始（macOS）

```bash
cd video-downloader-macos
bash 视频下载器-macOS.command
```

脚本会自动校验并下载运行依赖（yt-dlp、FFmpeg、Node，约 200MB，只下一次），随后打开浏览器界面。
停服务：`bash 停止视频下载器-macOS.command`

详细步骤见 `video-downloader-macos/INSTALL.md`。

## 能下什么

- **抖音**：视频与**图文（图集）**。图文会在保存目录里按作品标题自动建子文件夹，图片按序号命名，webp 自动转 jpg，单张失败自动重试。
- **B 站 / YouTube / 央视频** 等 yt-dlp 支持的站点：视频。
- 支持批量粘贴多个链接排队下载。

## 界面

- 亮色 / 暗色手动切换（记住选择，存在浏览器本地）。
- 运行状态可展开，实时看每张图 / 每个片段的进度。
- 下载完可直接打开所在文件夹。

## 说明

- 抖音解析用无头浏览器匿名抓取页面数据，**不读取、不保存任何 Cookie**；游客态可下大部分公开作品，个别作品需要登录才能看，这类下不了。
- 首次运行需要能访问外网下载依赖组件。
- 只监听 `127.0.0.1`，不对外暴露端口。
